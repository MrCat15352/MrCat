# Система Bounty Hunter

## Описание
Система Bounty Hunter позволяет игрокам создавать заявки на розыск других персонажей за вознаграждение. Это добавляет новый слой взаимодействия между фракциями и создаёт дополнительные возможности для ролевой игры.

## Функционал

### Основные возможности:
- **Создание заявок**: Игроки могут создавать bounty на любого персонажа
- **Указание статуса**: "Живым", "Мёртвым" или "Живым или мёртвым"
- **Установка награды**: Деньги списываются с корабельного счёта при создании заявки
- **Просмотр активных заявок**: Все могут видеть список активных bounty
- **Отмена заявок**: Создатель может отменить свою заявку и вернуть деньги

### Информация в заявке:
- Имя цели
- Фракция цели (опционально)
- Требуемый статус (живым/мёртвым)
- Причина розыска
- Размер награды
- Информация о заказчике (имя и фракция)
- Время создания заявки

## Использование

### Для создания заявки:
1. Вставьте ID карту в консоль Bounty Hunter
2. Перейдите на вкладку "Создать заявку"
3. Заполните информацию о цели:
   - Имя цели (обязательно)
   - Фракция цели (опционально)
   - Статус (живым/мёртвым/любой)
   - Причина розыска (обязательно)
   - Размер награды (обязательно)
4. Нажмите "Создать заявку"

### Для просмотра заявок:
1. Откройте консоль Bounty Hunter
2. На вкладке "Просмотр заявок" отображаются все активные bounty

### Для отмены заявки:
1. Вставьте ID карту создателя заявки
2. В списке заявок нажмите "Отменить" рядом с нужной заявкой
3. Деньги вернутся на корабельный счёт

## Игровое воздействие

### Положительные эффекты:
- Увеличивает взаимодействие между фракциями
- Создаёт новые возможности для ролевой игры
- Даёт InteQ и другим наёмникам дополнительные задачи
- Добавляет экономический элемент в конфликты

### Балансировка:
- Деньги списываются сразу при создании заявки
- Только создатель может отменить свою заявку
- Информация о заказчике всегда видна
- Нет автоматической выплаты - требует ручного взаимодействия

## Возможные расширения

В будущем систему можно расширить:
- Автоматическая выплата при подтверждении выполнения
- Система репутации bounty hunters

- Интеграция с системой безопасности станций
- Уведомления при создании новых заявок
