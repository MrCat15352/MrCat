# Графические библиотеки и технологии отрисовки орбитальной карты

## Основные графические технологии

### 1. SVG (Scalable Vector Graphics)
**Основная технология отрисовки карты**
- Нативная поддержка браузера
- Векторная графика для масштабирования без потери качества
- Используется в `OrbitalMapSvg.js`

#### SVG элементы:
- `<svg>` - основной контейнер карты (viewBox="-250 -250 500 500")
- `<circle>` - планеты, шаттлы, маяки, зоны перехвата
- `<line>` - векторы скорости, траектории, прицелы
- `<rect>` - сетка, паттерны заливки, цели
- `<text>` - названия объектов, координаты, скорости
- `<path>` - сложные формы для сетки
- `<pattern>` - повторяющиеся паттерны для фонов

### 2. CSS Patterns и Gradients
**Фоновые паттерны и заливки**
```scss
// Паттерны определены в SVG <defs>
- #grid - основная сетка карты
- #smallgrid - мелкая сетка
- #interdictionRange - зона перехвата (полосы)
- #planetfill - заливка планет (полосы)
```

### 3. Inferno.js
**React-подобная библиотека для UI**
- Легковесная альтернатива React
- JSX синтаксис для компонентов
- Виртуальный DOM для оптимизации

## Математические библиотеки

### common/math.ts
**Утилиты для вычислений**
```typescript
- clamp(value, min, max) - ограничение значений
- scale(value, min, max) - масштабирование
- round(value, precision) - округление
- toFixed(value, digits) - форматирование чисел
```

### Математические операции в коде:
- Тригонометрия: `Math.cos()`, `Math.sin()` для поворотов
- Векторная математика для позиций и скоростей
- Масштабирование координат: `* zoomScale * mapDistanceScale`
- Интерполация для плавной анимации

## Система рендеринга объектов

### Классы рендеринга (в OrbitalMapSvg.js):
1. **RenderableObjectType** - базовый класс
2. **PlanetaryBody** - планеты (оранжевые с паттерном)
3. **Beacon** - маяки (пульсирующие круги)
4. **Shuttle** - шаттлы (зеленые с траекториями)
5. **Projectile** - снаряды (красные линии)
6. **Broken** - поврежденные объекты (красные)

### Особенности рендеринга:
- **30 FPS** обновление анимации
- **Интерполация** позиций между обновлениями сервера
- **Culling** объектов за границами экрана
- **LOD** (Level of Detail) - разные размеры на разных масштабах

## Анимация и интерактивность

### Система анимации:
- `setInterval()` для 30 FPS обновлений
- Интерполация позиций: `position + velocity * elapsed * vel_mult`
- Плавное масштабирование и панорамирование

### Интерактивность:
- **Drag & Drop** для панорамирования карты
- **Mouse events** для кликов по объектам
- **Zoom** через кнопки интерфейса
- **Tracking** объектов с автоматическим следованием камеры

## Оптимизация производительности

### Техники оптимизации:
1. **Виртуализация** - рендеринг только видимых объектов
2. **Батчинг** - группировка SVG элементов
3. **Кэширование** - переиспользование рендер-объектов
4. **Culling** - отсечение невидимых элементов
5. **Интерполация** - плавность без частых обновлений сервера

### Управление памятью:
- Переиспользование объектов рендеринга
- Очистка таймеров при размонтировании компонентов
- Ограничение длины траекторий (20 точек для шаттлов)

## Цветовая схема

### Цвета объектов:
- **Планеты**: `#fca635` (оранжевый)
- **Шаттлы**: `#a4eea4` (зеленый)
- **Маяки**: `#f58473` (красно-розовый)
- **Снаряды**: `#FF0000` (красный)
- **Сетка**: `rgba(0, 255, 255, 0.15)` (голубой полупрозрачный)
- **Текст**: `white` (белый)
- **Зона перехвата**: `rgba(64, 194, 86, 0.05)` (зеленый полупрозрачный)

## Координатная система

### Система координат:
- **Центр**: (0, 0) в центре SVG viewBox
- **Диапазон**: -250 до +250 по X и Y
- **Масштабирование**: `zoomScale` для приближения/отдаления
- **Смещение**: `xOffset`, `yOffset` для панорамирования

### Преобразования:
```javascript
outputX = (position_x + xOffset + velocity_x * elapsed) * zoomScale
outputY = (position_y + yOffset + velocity_y * elapsed) * zoomScale
```

## Заключение

Орбитальная карта использует **чистые веб-технологии** без внешних графических библиотек:
- **SVG** для векторной графики
- **CSS** для стилизации и паттернов  
- **JavaScript** для анимации и интерактивности
- **Inferno.js** для управления компонентами
- **Собственная математика** для вычислений

Это обеспечивает высокую производительность, кроссплатформенность и простоту развертывания.
