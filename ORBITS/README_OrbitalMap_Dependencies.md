## Функциональность

### Основные компоненты
1. **OrbitalMap** - главный компонент интерфейса
2. **DisplayWindow** - переключение между режимами отображения

- **Projectile** - снаряды
- **Broken** - поврежденные объекты

## Взаимодействие с сервером

### Действия (act)
- `launch` - запуск шаттла
- `updateLinkedId` - обновление связи
- `updateDesignatorId` - обновление десигнатора
- `setTargetCoords` - установка координат цели
- `callShuttle` - вызов шаттла
- `setTarget` - установка цели автопилота
- `nautopilot` - переключение автопилота
- `toggleBreaking` - экстренное торможение
- `dock` - стыковка
- `interdict` - перехват
- `gotoPort` - переход к порту

### Данные от сервера
- `map_objects` - объекты на карте
- `linkedToShuttle` - связь с шаттлом
- `canLaunch` - возможность запуска
- `shuttleName` - имя шаттла
- `interdictionTime` - время перехвата
- `validDockingPorts` - доступные порты стыковки
- `shuttleTarget` - цель шаттла
- `fuel` - топливо
- `display_stats` - статистика

## КТО ИСПОЛЬЗУЕТ ИНТЕРФЕЙС

### 1. Серверные интерфейсы (DM код)

#### Основной интерфейс
- **`orbital_map_interface.dm`** - базовый интерфейс орбитальной карты
  - Класс: `/datum/orbital_map_tgui`
  - Открывает UI с именем `"OrbitalMap"`
  - Управляется подсистемой `SSorbits`

#### Портативная карта
- **`portable_orbital_map.dm`** - переносная навигационная карта
  - Класс: `/obj/item/navigation_map`
  - Предмет в игре, открывающий интерфейс `"OrbitalMap"`
  - Показывает данные в зависимости от местоположения игрока

### 2. Система орбитальных объектов

#### Основная система
- **`orbital_map.dm`** - управление орбитальной картой
  - Класс: `/datum/orbital_map`
  - Содержит все орбитальные объекты
  - Управляет зонами коллизий

#### Типы орбитальных объектов
- **Планеты:** `lavaland.dm`, `phobos.dm`
- **Станции:** `space_station.dm`
- **Шаттлы:** `shuttle.dm`, `custom_shuttle.dm`
- **Маяки:** `beacon.dm`
- **Звезды:** `star.dm`
- **Метеоры:** `meteor.dm`

### 3. Система генерации контента

#### Генератор POI
- **`orbital_poi_generator/`** - генерация точек интереса
- **Типы заданий:** артефакты, убийства, эвакуация VIP
- **Генераторы руин:** астероиды, экзопланеты

### 4. Подсистема орбит

#### SSorbits
- Управляет всеми открытыми интерфейсами орбитальных карт
- Обновляет данные карты в реальном времени
- Обрабатывает перехват шаттлов
- Связывает шаттлы с орбитальными объектами

### 5. Игровые объекты

#### Консоли и устройства
- Консоли управления шаттлами
- Навигационные терминалы
- Портативные карты-планшеты

#### Шаттлы
- Все шаттлы в игре могут использовать орбитальную карту
- Система стыковки и навигации
- Автопилот и ручное управление

### 6. Стили и ресурсы
- **`OrbitalMap.scss`** - стили интерфейса
- **`bg-orbital.png`** - фоновое изображение

## Обратные зависимости

### Кто зависит от OrbitalMap.js:
1. **Система навигации шаттлов** - основной пользователь
2. **Система исследования космоса** - для отображения POI
3. **Система перехвата** - для локальных карт
4. **Генераторы контента** - для размещения объектов
5. **Подсистема орбит** - для отображения данных

### Игровые сценарии использования:
- Пилотирование шаттлов между станциями
- Исследование космических руин
- Навигация к точкам интереса
- Перехват других шаттлов
- Стыковка с космическими станциями
- Мониторинг орбитальной обстановки
