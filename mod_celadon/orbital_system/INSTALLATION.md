# Инструкция по установке орбитальной системы

## Требования

- MrCat билд с поддержкой модпаков
- TGUI система
- Права администратора для настройки

## Установка

### 1. Файлы уже установлены
Орбитальная система уже интегрирована в билд MrCat как модпак `orbital_system`.

### 2. Активация системы

В файле `config/config.txt` раскомментируйте строку:
```
ORBITAL_MODE_ENABLED
```

### 3. Перезапуск сервера
Перезапустите сервер для применения изменений.

## Проверка работы

### Для администраторов
1. Используйте команду `Toggle Orbital Mode` в меню Admin.Game
2. Откройте `Open Orbital Map` для просмотра карты
3. Используйте `Orbital Debug Panel` в меню Debug для диагностики

### Для игроков
1. Призраки могут использовать команду "Показать орбиты"
2. Навигационные консоли автоматически переключаются в орбитальный режим

## Настройка производительности

### Автоматическая оптимизация
Система автоматически включает режим производительности при высокой нагрузке.

### Ручная настройка
Администраторы могут использовать Debug Panel для:
- Переключения режима производительности
- Мониторинга статистики
- Управления тестовыми объектами

## Отладка

### Логи
Проверьте логи сервера на сообщения:
- `ORBITAL SYSTEM: Configuration validation passed`
- `ORBITAL SYSTEM: Shutting down gracefully`

### Частые проблемы

**Проблема:** Орбитальная карта не открывается
**Решение:** Проверьте, что `ORBITAL_MODE_ENABLED` активирован в конфиге

**Проблема:** Низкая производительность
**Решение:** Система автоматически оптимизируется, или используйте Debug Panel

**Проблема:** Ошибки в логах
**Решение:** Используйте `Orbital Debug Panel` для диагностики

## Деактивация

Для отключения орбитальной системы:
1. Закомментируйте `ORBITAL_MODE_ENABLED` в конфиге
2. Перезапустите сервер
3. Система вернется к стандартной overmap навигации

## Поддержка

При возникновении проблем:
1. Проверьте логи сервера
2. Используйте Debug Panel для диагностики
3. Обратитесь к разработчикам с подробным описанием проблемы
