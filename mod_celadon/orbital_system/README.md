# Орбитальная система навигации

Дополнительная система навигации для MrCat, основанная на орбитальной механике из WHITE-SHIPTEST.

## Возможности

- Физическая симуляция орбит с гравитацией
- Векторная система движения
- TGUI интерфейс орбитальной карты
- Переключение между overmap и orbital режимами
- Админские команды управления

## Использование

### Для игроков
- Призраки: команда "Показать орбиты" в меню призрака
- Навигационная консоль: автоматически переключается между режимами

### Для администраторов
- `Toggle Orbital Mode` - переключение режима навигации
- `Open Orbital Map` - открытие орбитальной карты
- Конфиг: `ORBITAL_MODE_ENABLED` в config.txt

## Конфигурация

В `config/config.txt`:
```
## Orbital system mode toggle
## Uncomment to enable orbital navigation instead of overmap
#ORBITAL_MODE_ENABLED
```

## Структура

- `code/` - основная логика подсистемы
- `components/` - компоненты орбитальной карты и векторов
- `objects/` - орбитальные объекты (планеты, станции, шаттлы)
- `interface/` - TGUI интерфейсы
- `tgui/` - JavaScript компоненты
